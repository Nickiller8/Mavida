# Mavida
AI + Language project for Veritas AI International High School Hackathon 2026

Language Identification System 🌍

This project is a machine learning-based language identification system.
It analyses a sentence entered by a user and predicts the language in which it is written.
The system uses Natural Language Processing (NLP) and machine learning to identify languages.

The following languages are identified:
- English
- French
- Portuguese
- Shona
- Spanish
- Mandarin Chinese

The following technologies were used in the process of making this:
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression
- Streamlit
- Google Colab
- GitHub
- Tatoeba Dataset

The system uses:
1. TF-IDF Vectorization to convert text into numerical features.
2. Character n-grams to identify patterns in words and sentences.
3. Logistic Regression to classify sentences according to language.

The model is trained and evaluated using training and testing datasets.

The user enters a sentence into a Streamlit interface.
The trained machine learning model processes the sentence and displays its predicted language.

The main objective of this project is to develop a simple and accessible language identification tool that can automatically recognise the language of a given sentence.
